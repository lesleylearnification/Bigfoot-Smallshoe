# Build 6 Brand System

## Primary identity

The Bigfoot Smallshoe logo is an expedition-style title lockup with weathered cream lettering, a dark forest-green shadow, and a five-toed footprint emblem.

## Typography

- Logo: condensed vintage serif
- Display: sturdy condensed sans serif
- Body: readable book serif
- Labels: uppercase ranger-form sans serif
- Notes: sparingly used handwritten style

No font files are distributed with the project. The CSS uses widely available system font stacks.

## Rules

1. Use the official SVG logo rather than recreating the title as normal page text.
2. Body text must always sit on a calm, high-contrast reading surface.
3. Warm lantern light and cool forest light remain the primary lighting relationship.
4. Digital gradients, glossy buttons, and generic cards are prohibited.
5. Materials must feel physically plausible inside Bigfoot's cabin.
