# Bigfoot Smallshoe Production Documentation Index

## Vision and standards

The final build implements the agreed Build 6 guiding principle:

> Every screen should feel like a handcrafted page from Bigfoot Smallshoe's life. The interface is never separate from the world. The cabin is the menu. The journal is the UI. Every interaction reinforces the quiet power of recognizing people whose work might otherwise go unnoticed.
