# Bigfoot Smallshoe
## Build 6.0 · Art Lock

**Helping everyone. Seen by no one.**

Bigfoot Smallshoe is a handcrafted browser game in which players practice five meaningful employee-recognition behaviors while quietly helping the people of Smallshoe Forest.

## Start the game

Open `index.html`, or serve the project locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish on GitHub Pages

See [GITHUB_PAGES_DEPLOYMENT.md](GITHUB_PAGES_DEPLOYMENT.md).

## Run quality checks

```bash
npm test
```

No dependency installation is required.

## Included systems

- Bigfoot’s interactive cabin
- Smallshoe Forest map
- 25 recognition scenarios
- Randomized five-scenario expeditions
- Hidden multidimensional scoring
- Evidence Satchel
- My Trail vs. Expert Trail reflection
- Five-footprint self-ratings
- Ranger Reports and newspaper outcomes
- Field Guide Cabinet with 30 research sources
- Saved Field Notes
- Quiet Legends
- The Forest Remembers
- Persistent progression
- Multiple endings
- Original lightweight audio
- Motion, sound, text-size, contrast, and screen-announcement controls
- Responsive desktop, tablet, and mobile layouts
